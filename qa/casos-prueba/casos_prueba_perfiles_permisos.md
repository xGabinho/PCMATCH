# Casos de Prueba Funcionales - Módulo de Gestión de Perfiles y Permisos

## Resumen del Módulo
El módulo de Gestión de Perfiles y Permisos administra los roles y privilegios granulares del sistema. Permite a los administradores crear perfiles personalizados con un catálogo de permisos asignados, modificar el conjunto de permisos de un perfil existente, activar o desactivar perfiles, asignar o remover perfiles a usuarios específicos y eliminar perfiles garantizando la desvinculación automática de usuarios asociados.
