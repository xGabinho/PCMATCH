# Casos de Prueba Funcionales - Módulo de Autenticación y Perfil de Usuario

## Resumen del Módulo
El módulo de Autenticación y Perfil gestiona las operaciones de inicio de sesión de tres entidades del sistema (Usuarios clientes/admin/superadmin, Bodegas y Proveedores), registro de clientes, recuperación y restablecimiento de contraseña mediante token expirable (60 minutos), así como la visualización y edición del perfil del usuario autenticado.
